# Trademark policy

> **Draft, pending legal review.** The product name has not been chosen yet; `[Product name]` is a placeholder.

The AGPL covers the source code. It does not grant rights to the project's name or logo.

Intended policy once a name exists:

- You may say that your software is based on or compatible with [Product name], truthfully and without implying endorsement.
- You may not use the name or logo for a modified version, a competing hosted service or a company name in a way that suggests it is the official product.
- Forks that are distributed to others should use a different name and logo.

Questions about use of the name can be raised in a GitHub issue.
